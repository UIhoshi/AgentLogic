# AgentLogic Frontend Templates

These are original, unbranded HTML/CSS starting points for frontend work. They complement the
Taste skill: **Taste governs the design decision and verification; these files provide a small,
editable implementation baseline.**

## Included templates

| File | Use when | Primary pattern |
| --- | --- | --- |
| `editorial-landing.html` | Launching a product, feature, or campaign | Editorial hierarchy and asymmetric hero |
| `analytics-dashboard.html` | Showing operational or product metrics | Dense, scannable data layout |
| `settings-surface.html` | Editing account, workspace, or product configuration | Clear form hierarchy and safe actions |

## Use safely

1. Copy the smallest matching template into the target project; do not edit these reference files
   for one product.
2. Replace the CSS variables in `foundation.css` with the project's tokens before adding new
   one-off colours or spacing values.
3. Replace placeholder content, names, and numbers. Add only project-owned images, fonts, icons,
   and copy with known rights.
4. Use the UI preview/approval gate before formal project UI implementation, then verify the
   rendered narrow and wide layouts with screenshots.

## Boundaries

- No network requests, third-party fonts, images, logos, or copied UI assets are included.
- The templates are static references, not a component library or a runtime dependency.
- Preserve semantic landmarks, labels, focus states, reduced-motion behavior, and responsive
  layout safeguards when adapting them.
